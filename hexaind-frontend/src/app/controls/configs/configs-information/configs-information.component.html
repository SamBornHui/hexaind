XGBoost (eXtreme Gradient Boosting) is a powerful and widely used machine learning algorithm, primarily designed for structured/tabular data. It is based on the concept of gradient boosting, which combines multiple weak models (decision trees) to form a strong model. Successive rounds of boosting are built by minimizing the errors of the previous models, allowing each new model to correct the mistakes made by the earlier ones. The parameters in the Parameters tab enable you to customize various aspects of the model construction process.

Train/test split:

The data will be split into training and testing sets, with the user selecting the test set ratio (𝛼). For a "Random Split," the data is randomly divided between training and testing sets, and a specific random state (e.g., 42) can be set in the 'Advanced parameters' for reproducibility. By default, no random state is defined, resulting in different splits each time. For a "Sequential Split," the first (1-𝛼) fraction of the data is used for training, and the remaining 𝛼 is used for testing, useful when data order matters or is already shuffled.

Input feature scaling:

The user can choose from three type of scaling, Standard (mean-centered wihg standard deviation), MinMax (rescale to [0,1] range), and Robust (scale to interquartile range IQR=Q3-Q1 and median-centered), or no scaling. The scaler is fitted on the training data only, and then applied to both training and testing sets to prevent bias from the testing set.

Note that for XGBoost, input scaling isn't strictly necessary as trees are not sensitive to the scale of the features.

Building the model:

XGBoost builds the model through successive rounds of boosting, where each boosting round optimizes a decision tree of a specified maximum depth to minimize the overall error. The learning rate controls how much influence each new tree has on correcting the errors from previous rounds. Fine-tuning the number of estimators, maximum depth, and learning rate can significantly improve model performance: increasing the number of estimators generally leads to better accuracy but can cause overfitting; adjusting the maximum depth helps control model complexity; and selecting an appropriate learning rate balances convergence speed and stability.

Advanced Parameters:

Other parameters can be used to fine-tune the model, especially to avoid overfitting and improve model robustness. For example, 'subsample' controls the fraction of the training data used in each boosting iteration to introduce randomness, while 'colsample_bytree', 'colsample_bylevel', and 'colsample_bynode' control the fraction of features used at different stages of tree construction to further reduce overfitting and enhance model diversity.

Boosted or standalone Random Forest:

XGBoost can also implement parallel trees to create a Random Forest-like model. In this approach, multiple trees are built independently in parallel to reduce variance and improve robustness. When the number of estimators is set to 1, XGBoost functions as a standalone Random Forest, leveraging ensemble techniques without boosting.

Building the model:

The model is built based on the user-defined polynomial degree. The higher the polynomial degree, the more complex the model becomes, allowing it to capture complex relationships within the data. However, increasing the polynomial degree can lead to overfitting, and the model will fit the noise in the data and not the main pattern.

The widget allows for separate control of the polynomial degree of each feature, providing greater flexibility in model tuning, especially when features exhibit different levels of complexity.
